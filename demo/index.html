ReleaseForge — TUI demo

A scripted tour of the actual Bubble Tea interface. Each frame is the real Model.View() output captured with colors, then translated from ANSI to HTML — not a mock-up. The app's intent is unchanged: a local command bar plus live windows for scan, build, test, git, logs and release work.
